# SmaranQ Downloads

Public installers and release notes for [SmaranQ](https://smaranq.com/#download), a macOS meeting intelligence app by Raj Kumar.

SmaranQ is alpha software and still in development. Report bugs to [contact@rajsharma.space](mailto:contact@rajsharma.space), including your Mac model, macOS version, and reproduction steps. Remove private meeting content from attachments.

See each release for compatibility, trial dates, checksums, signing status, known limitations, and installation instructions. This repository distributes app binaries and documentation.
